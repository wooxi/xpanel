# XPanel

专为 Hysteria 2 与 NodeX 打造的轻量级节点管理与多格式订阅服务。

---

## 🌟 服务特点

- **极简极轻**：常驻内存仅 10MB+，启动秒级响应，告别臃肿的运行环境。
- **纯粹面板**：面向个人与小团队自用设计，纯管理员后台管控，无支付网关、工单系统、前台注册等冗余流程。
- **专精 HY2**：专为 Hysteria 2 协议深度定制，贴合内核参数特性。
- **原生兼容 NodeX**：无缝对接 NodeX 节点管家（UniProxy），节点端零改造即插即用。
- **全客户端订阅**：原生输出 Clash / Mihomo、Shadowrocket、通用 Base64 等主流客户端格式，支持在线自定义订阅模版。
- **开箱即用**：提供标准 Docker 容器化编排，单步骤快速部署，数据独立持久化。

---

## 📋 功能清单

### 1. 仪表盘与监控
- **集群状态概览**：实时展示在线节点数、有效用户数、今日流量消耗及历史累计用量。
- **节点状态监控**：直观展示每个节点的最后通信时间与心跳上报状态。

### 2. 节点管理
- **Hysteria 2 节点配置**：支持节点域名/IP、服务端口、SNI、证书跳过校验（Insecure）、混淆类型及密码（Salamander）、上行/下行带宽速率等完整属性设置。
- **对接信息一键生成**：一键生成并复制 NodeX 所需的节点 ID、独立通信 Token 及服务端点。
- **节点启停**：支持单独启用/停用特定节点。

### 3. 用户与权限管理
- **用户档案控制**：添加、编辑、删除用户，设定独立到期时间与流量配额（支持不限流量或自定义 GB/TB 配额）。
- **状态控制**：支持一键停用/启用用户；到期或流量超限自动暂停节点鉴权。
- **密钥重置**：一键重置用户 UUID（即连接密码）或重置用户订阅安全 Token。
- **流量校准**：支持查看用户上传/下载明细，可根据需要随时清零或调整用户已用流量。

### 4. 订阅服务
- **多客户端格式分发**：
  - **Clash / Mihomo**：输出完整规则集与策略组配置（支持自动测速组与手动选择组）。
  - **Shadowrocket**：输出专用订阅列表，首行显式展示用户配额、用量及到期时间。
  - **通用 Base64**：提供通用订阅链接，并根据客户端 `User-Agent` 智能自适应下发对应格式。
  - **单节点链接**：提供标准 `hysteria2://` URI 单节点链接，方便快速导入测试。
- **在线模板定制**：后台内置 Clash 模板编辑器，可随时调整规则与策略组，并支持一键恢复内置默认模板。
- **友好防清空机制**：用户到期或超量时，订阅接口返回提示性节点而非错误码，避免客户端误删除已有节点配置。

### 5. NodeX 节点管家联动
- **配置下发**：节点周期性从面板获取端口、带宽限制、混淆等运行参数。
- **用户同步**：自动向节点下发当前有效用户的 UUID 白名单与限速策略。
- **流量与在线打卡**：自动接收节点周期性推送的流量增量数据并按日归档，支持在线 IP 与心跳状态上报。

### 6. 系统安全与设置
- **系统设置**：支持自定义站点名称、订阅显示名称、面板对外公开访问地址。
- **安全控制**：内置后台防爆破锁机制，支持随时在 Web 控制台修改管理密码。

## 🚀 快速开始

### 1. 使用 Docker Compose 部署

克隆仓库或下载文件到部署目录：

```bash
mkdir -p /opt/xpanel && cd /opt/xpanel
```

配置 `.env` 环境变量：

```bash
cat << 'EOF' > .env
ADMIN_USER=admin
ADMIN_PASS=SetYourSecurePasswordHere
EOF
```

启动服务：

```bash
docker compose up -d
```

服务默认监听 `7002` 端口，通过浏览器访问 `http://<服务器IP>:7002` 即可登录管理后台。

> **提示**：首次启动时会使用 `.env` 中的凭据初始化管理员账号，之后可在后台「设置」页面直接修改密码。

---

## 🔗 对接 NodeX

1. 在 XPanel 后台「节点」页面创建新节点，点击「复制对接信息」获取该节点的通信 Token 与节点 ID。
2. 打开 NodeX 节点管理页面，填入对应参数：

| NodeX 参数 | 填写内容 |
| :--- | :--- |
| **面板地址** | `http://<面板IP或域名>:7002` |
| **面板 Token** | 节点详情中生成的 Token |
| **节点 ID** | 节点列表中对应的数字 ID（如 1、2...） |
| **节点类型** | 留空 |
| **拉取 / 推送间隔** | 建议填写 `60`（秒） |

保存后 NodeX 即可自动拉取节点参数与用户列表，并开始上报流量与心跳状态。

---

## 📱 客户端订阅链接

在后台「用户」列表中点击对应用户的「订阅」按钮即可查看和复制订阅链接：

| 客户端类型 | 链接格式 | 说明 |
| :--- | :--- | :--- |
| **Clash / Mihomo** | `http://<面板地址>/sub/<TOKEN>?flag=clash` | 输出 YAML 规则集及策略组 |
| **Shadowrocket** | `http://<面板地址>/sub/<TOKEN>?flag=rocket` | 输出包含状态提示行的 Base64 订阅 |
| **通用自适应** | `http://<面板地址>/sub/<TOKEN>` | 依据客户端 UA 自动匹配最佳格式 |
